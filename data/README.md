# data/

真实业务数据**不进 Git**（见 `.gitignore`）。这里只放样例结构与说明。

```
data/
├── raw/            # 客户原始素材（Excel、图片、邮件导出）—— 本地保留，已忽略
├── samples/        # 脱敏后的样例，可入库，用于测试与演示
└── fixtures/       # 测试用固定数据集（小、稳定、可复现）
```

**入库规则**

1. 客户名、联系方式、精确价格 → 脱敏成 `Customer-A`、`¥***`。
2. 图片仅保留可对外公开的样品图。
3. 合同、报关单、税务材料只做结构提取，原件不入库。

**samples/ 现有样例**

| 文件 | 来源与用途 |
|---|---|
| `生产指令单-样板.xlsx` | 依真实多行生产指令单结构脱敏生成（公司/地址/单号/产品编号/条码全部合成化，内嵌图片移除），用于打表导入闭环的回归与演示 |
| `采购合同-样板.xlsx` | 依真实采购合同结构脱敏生成（sheet 名、公司、合同号合成化），用于采购计划打表导入演示 |

见 [../docs/03-数据与素材清单.md](../docs/03-数据与素材清单.md)。
