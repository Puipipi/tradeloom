## 一、为什么是这件事

真实场景，不是设想。

广交会前十五天，老板一个人在干这些事：样品要拍、图片要分类、图片要处理成印刷厂能用的格式、要按画册版式排好、报价单要重算一遍。**十五号交设计稿，十九号打包。** 这件事和「客户在 WhatsApp 上问价」「车间在问这个单先做哪道工序」同时发生，而公司里没有一个地方同时装着这三件事。

老板自己的总结是五个问题：

| 环节 | 老板的原话 |
|---|---|
| 选品 | 「怎么选？」—— 哪类产品畅销、各国偏好、流行趋势，一般大厂才有人做调研 |
| 客户 | 「怎么找？」—— 海关数据「可以查，但是数据不够精准」 |
| 报价 | 「怎么报？」—— 要找到那个「度」：报出客人能接受的最高价，取多少利润比合适 |
| 生产 | 「怎么做？」—— 日报表 → 平均效率 → 工价 → 考核 → 交期预警 |
| 财务 | 「现金流怎么才能健康？怎么合规合理少花钱？」—— 账是外包的，一年 1500 元 |

## 二、问题不是「缺个 AI」，是「链路断了」

| 环节 | 今天怎么做 | 真正卡在哪 | TradeLoom 的切入点 | 依赖的输入 |
|---|---|---|---|---|
| **选品** | 行业经验 + 客户寄样 + 展会现场 | 「为什么这个款卖得好」只存在老板脑子里，不可复用、不可交接 | 把成交记录、样品图、客户询盘、外部趋势做成可检索的**选品证据链**，输出「可立项 / 需验证 / 放弃」和理由 | 成交单、样品图、询盘、客户偏好 |
| **找客** | 展会 + 国际站 + 老客介绍 + 海关数据 | 询盘质量参差，跟进全靠记性和人 | 询盘**打分**、按国家/渠道生成跟进节奏、多语种首响应草稿 | 邮件 / WhatsApp / 微信、海关数据 |
| **报价** | Excel 成本表 + 多年经验 | 报高了丢单，报低了白干；那个「度」无法解释、无法传承 | 成本模型 + 历史成交区间 + 客户画像 → **给区间、给理由、给人拍板** | 成本表、历史报价单、成交记录、付款条件 |
| **生产** | 纸质/微信日报表 + 车间喊 + 买了不用的 ERP | 数据采不上来，交期靠猜，效率算不清 | 拍照/语音/群消息 → 结构化日报 → 人均效率、工价、**交期预警** | 工序表、工价表、日报样例、排产表 |
| **财务** | 外账 1500 元/年 + 老板自己盯现金 | 看不见订单级的现金曲线；合规靠别人提醒 | 订单级现金流预测 + 合规/汇率/退税提醒 | 付款条件、账期、退税单据 |

## 三、三条设计原则（用来砍需求）

1. **不替老板拍板，只让拍板可复算。** 每个建议都要能点开看到依据（哪几单、哪个客户、哪份成本表）。
2. **不要求企业换系统。** 微信、Excel、纸质日报就是数据库；Agent 负责把它们变成结构。
3. **每个功能对着一个真实死线验收。** 「十五号交稿」「十九号打包」「这周五前给客户回价」——没有死线的功能先不做。

## 五、Roadmap（v0.1 假设，待评审）

| 阶段 | 目标 | 验收标准 |
|---|---|---|
| **P0 · 现在** | 需求基线与数据可得性确认 | 访谈问题表回收 ≥ 1 家真实企业；拿到 ≥ 30 份真实报价单/成交单 |
| **P1 · 展会切片** | 「样品图 → 可印刷画册页 + 报价单」一条流水线 | 老板给 20 张样品图 + 1 份价格表，产出的 PDF 印刷厂可直接收，人工复核时间下降 ≥ 50% |
| **P2 · 报价陪跑** | 报价 Agent 给出区间与理由 | 用历史 20 单回测：区间命中率、与老板实际报价的偏差可解释 |
| **P3 · 一单到底** | 从询盘到回款的订单视图 + 交期预警 | 真实订单跑通一个完整周期 |
| **P4 · 生产现场** | 日报表抽取与效率/工价看板 | 车间用手机发一句话/一张图即可完成日报 |

> 距初赛材料提交约 6 周（2026-12）。6 周只够把一条链路做到「能自己跑、能给人看」；三条各做一半，等于三条都不成立。
> **六周内的执行版排期见 [设计文档 §7](docs/specs/2026-10-17-tradeloom-design.md)**，P3/P4 属于「未来工作」，不在这 6 周里。

## 六、为什么叫 TradeLoom

Loom 是织机。这家企业的日常，本质是把五根线（选品、客户、报价、生产、财务）织成一匹布——今天这五根线在老板手里打了个结，我们要做的是那台**把线并起来、张力可调、断了会报警**的织机。

TradeLoom = Trade + Loom。中文名「贸织」：贸（接单）与织（生产），正好是「工贸一体」的两半。

## 七、English Abstract

TradeLoom is an agentic digital workforce for small export-oriented manufacturers that both trade and produce ("工贸一体"). It stitches the five fragmented workflows — product selection, customer acquisition, quotation, shop-floor execution, and cash flow — into one auditable loop. Every recommendation ships with its evidence (which orders, which customer, which cost sheet); human judgement stays in charge, while the agent does the remembering, the drafting, the reconciling, and the chasing.
