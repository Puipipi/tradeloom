如何获取 SMTP 配置

阿里企业邮箱

  1. 请邮箱管理员确认发件账号允许第三方客户端登录，并已开通 SMTP 服务。
  2. 在阿里邮箱网页版打开「设置 → 查看更多设置 → 账户与安全 → 账户安全」。开启「三方客户端安全密码」，点击「生成新密码」并完成身份验证。密码只显示一次。
  3. SMTP 主机填 smtp.qiye.aliyun.com，端口填 465，加密方式选 SSL/TLS。SMTP 账号填完整企业邮箱地址，授权密码填生成的专用密码，发件邮箱填同一邮箱。代发须经邮箱服务商授权。
  4. 保存后，用自己控制的内部账号请求一次验证码，在收件箱或垃圾邮件中核对发件地址。

其他服务商请查官方发件服务器、端口、加密方式和授权码说明。服务商明确支持时，可用端口 587 和 STARTTLS。
