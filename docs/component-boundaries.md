# 工作台对象与组件边界

状态：2026-10-25 前后端已共同确认。此文件描述职责与落地方向，不表示功能已部署或验收。

## 按用户的工作对象分类

| 对象 | 用户在这里做什么 | 应承载的内容 | 不应混入的内容 |
| --- | --- | --- | --- |
| 业务场景 | 处理一类业务工作 | 当前业务对象、相关资源、关联助手、待确认事项 | 全局设置、API 提供商管理、没有业务依据的示例工具 |
| 角色助手 | 按某种能力协作 | 通用能力、工具与技能配置、角色说明 | 将角色名称直接当成唯一会话身份 |
| 会话 | 延续一段明确的沟通历史 | 原生 DSH 历史、模型选择、工具、附件草稿、视图与归档 | 因点击不同场景而无提示地串入另一任务的历史 |
| 资料来源 | 查看原始业务证据 | 来源版本、图片、表格、坐标及确认状态 | 将历史文件自动关联成同一笔现行业务 |
| 附件草稿 | 准备交给某次会话的文件 | 本次待发送文件或引用 | 已审核业务事实、已经交付的成果 |
| 交付物 | 查看生成或整理后的成果 | 成果版本、生成来源、相关任务与运行 | 与原始资料混成无法辨认的文件清单 |
| 文件面板 | 找到并选择资源 | 来源、交付物、附件的明确类型及位置 | 同时承担所有业务的编辑表单 |
| 预览面板 | 呈现当前选中的资源 | 与所选文件的身份、版本保持一致的预览 | 因切换场景而静默显示上一个场景的不同资源 |
| 外部 AI 网页 | 在真实第三方网页交互 | 独立登录会话、网页窗口、显式文件输入与结果保存 | 原生 API 模型选择、原生角色聊天、伪造登录状态 |
| 工作计划 | 决定要做哪些业务步骤 | 步骤、依赖、人工确认与计划状态 | 将编辑计划或画布本身记为一次成功执行 |
| 执行画布 | 配置及观察一次节点执行 | 执行定义、节点关系、模式、节点结果与人工审核 | 把模拟输出标成真实外部系统调用 |
| 运行记录 | 追溯已发生的执行 | 明确标识的业务运行或画布运行、时间、结果、错误与来源 | 用诊断日志替代业务记录，或合并不同类型的 ID |
| 工具与设置 | 配置或维护工作环境 | 全局插件、模型 API、技能/MCP 配置、连接状态、诊断 | 将这些配置包装成与商品、生产并列的业务任务 |

## 当前混用与迁移边界

1. `scenes.json` 的 `roleId` 是默认助手能力，目前多个场景会按角色复用会话。它不证明这些场景属于同一任务。先保留现有绑定与历史；在身份迁移前明确显示共享范围，不自动开新会话、解除归档或迁移历史。
2. `user-profile` 演示角色不是客户资料库，也不是资料导入器的身份。不能仅因为都叫“资料”而共享权限、字段或会话。
3. `/artifacts` 当前同时呈现来源和交付物。复用资源浏览与预览能力，但保留资源类型、版本及来源；附件草稿继续由会话拥有。
4. “工作流”目前同时包含业务计划页签和画布。保留已有容器及布局 ID，但让两个页签对应不同对象；执行历史带 `recordKind`，区分 `business_run` 与 `canvas_run`。
5. `AgentRun` 与 `CanvasWorkflowRun` 是不同记录。后端不得以两者主键偶然相同建立关联；需要关联时显式保存来源标识。
6. ERPNext 服务连接属于工具。业务单据操作属于对应业务工作；不要再创建一个包含无关占位组件的通用业务场景。
7. 顶部外部网页入口独立于原生 composer 模型选择。网页 `ready` 只表示文档加载；`delivered` 只表示文件交给网页，均不证明登录、问答或解析成功。

## 协作规则与最小落地

- 不根据离线包的专用示例预造 24 种面板，不执行其私人规则，不复制占位路径。
- 保留稳定的场景、面板及资源 ID，避免分类调整破坏已保存布局和草稿。
- 前端拥有导航、场景配置、组件呈现与样式；后端拥有对象身份、授权、状态、来源、执行及持久化。
- 两方先确认此映射。首批实现应让导航、文件类型、会话共享范围及运行记录类型一致，而不是仅改显示名称。
- 未确认的生产报工口径继续待确认。人工估算工时不能自动变成精确产量或工资事实；涉及金额的计算保留明确口径和精度。

## 边界验收场景

1. 同一角色进入两个不同业务场景：能看出是否共享会话，不静默覆盖草稿或历史。
2. 选中原始 Excel，再选生成报告：文件和预览同步切换，资源类型、版本、来源保持正确。
3. 会话附件尚未发送：不出现在已交付成果中；关闭回坞与主题切换不丢失附件。
4. 画布模拟成功、真实调用失败：运行记录能分别识别，不出现混合的“成功”。
5. 原生会话已归档：仍保留归档意图，不因为进入场景而自动解除归档或重新发送消息。
6. 外部网页未登录或受站点限制：入口仍可说明状态，不显示为模型 API 已配置或已完成网页问答。
