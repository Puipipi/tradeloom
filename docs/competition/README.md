# 赛事材料（初赛 / 总决赛）

官方模板原样放在这里，**不要改模板结构**（评委会按模板读）。填写用脚本生成，改内容就跑脚本，别手改 Word。

| 文件 | 说明 |
|---|---|
| `赛题2-模板1-作品信息收集表-空白.docx` | 官方模板（初赛提交物） |
| `赛题2-模板2-答辩PPT-空白.pptx` | 官方模板（中国总决赛提交物，4 页骨架，自己扩到 ≤20 页） |
| `赛题2-作品信息收集表-TradeLoom-填写稿.docx` | 已填版本，由 `scripts/fill_form.py` 生成 |

**重新生成填写稿**：

```powershell
.\.venv\Scripts\python.exe scripts\fill_form.py
```

内容集中写在 `scripts/fill_form.py` 顶部的 `FIELDS` 里。要改文案，改那里，别改 docx。
