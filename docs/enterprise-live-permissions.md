# 已登录窗口的权限更新

个人端菜单及服务器业务/控制台页面在窗口获得焦点、页面重新可见时重新核对权限。正常可见期间每 5 秒核对一次，单次请求最多 8 秒；同一个检查器不会重叠请求。更新有观察间隔，并非即时推送。

检查使用当前同源 Session 的只读 `/enterprise/capabilities/?ui=1`，只计算当前用户、组范围、权限和角色标志，不查询业务资料、密钥或外部模型。服务器 HTML 使用进入视图前的权限快照，防止渲染期间发生的降权被误记为旧资料的新权限。

权限稳定时不重载页面、不重建原生菜单，保留未提交表单。确认权限变化后先移除旧内容，再在同一窗口、同一受信 origin 打开可访问的页面；受限的控制台或业务资料回到企业首页。恢复权限时同一页面会重新展示当前允许的入口。

纯网络错误不会改连接配置、注销 Session 或刷新页面。页面暂停新增操作并保留输入，原生特权菜单禁用；核对恢复后自动恢复操作。每个特权请求原有的服务器核权和个人端点击核权仍然保留。后台隐藏页面不持续轮询，恢复可见时立即检查；既有本机管理 grant 的路径边界保持不变。
