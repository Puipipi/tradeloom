# 助手内的登记员账号状态管理

个人端原“服务端助手”和服务器企业控制台使用同一入口。安装管理员可输入“查询登记员 完整用户名”“停用登记员 完整用户名”“启用登记员 完整用户名”，或使用“登记员账号状态”控件。这些命令由本应用确定解析，不需要模型密钥，不向模型发送账号信息。

权限完全复用“工厂与登记员设置”：有效、非冲突的安装超级管理员可以操作；普通老板、技术员、本机受限诊断身份和登记员不能操作。目标必须是原设置页可管理的普通工厂登记员；管理身份、混合角色、直接授权和带权限工厂组均拒绝。输入的是内部用户名，不是昵称；大小写无法唯一定位时须填写准确用户名。

查询显示账号ID、用户名、所属工厂及当前登录状态，不返回密码、邮箱或原始授权数据。启停先显示当前状态和请求状态，账号尚未更改。核对后点击“确认更改登记员状态”并确认；点击“取消提案”会作废提案，账号不变。取消最后的确认对话框仅保留提案供继续核对。

提案仅属于当前登录账号与会话，120秒有效。确认时重新检查操作者管理权限，以及目标的身份、工厂、权限和当前状态；变化后提案作废，须重新查询并准备。过期、取消、已确认或已经拒绝的提案不能重放。当前已经是请求状态时只返回结果，不生成提案或重复写入。

实际变更仅保存目标的“允许登录”状态，不改变密码、邮箱、角色、工厂或历史记录。停用后的下一次请求按现有身份检查拒绝业务；恢复后通过原账号密码及邮箱验证码正常登录。管理事件只记录固定动作、操作者与目标ID及结果，不记录输入全文、密码或提案token。

其它自然语言保留原DeepSeek分类能力，但服务端仅在本次请求包含明确的布尔同意值时读取模型密钥并发送问题。没有同意时不外发；本地公告和登记员命令不依赖该同意。不增加任意Shell、工具调用、业务agent或独立官网关联。

## 开发复测

在专用已创建的PostgreSQL测试库运行，并保持测试库与业务库不同：

```powershell
python -B manage.py test enterprise_portal.tests_registrar_assistant enterprise_portal.tests_website enterprise_portal.tests_registrar_setup enterprise_portal.tests_cloudflare --settings=config.enterprise_settings --keepdb
```

覆盖真实状态写入、取消、无变化、跨会话、过期、重复提交、目标工厂/状态/角色变化、管理员撤权后确认及恢复后重放拒绝、CSRF和服务器外发同意。模型路径使用合成分类器，不代表外部provider实网可用。完整客户端渲染和真实外部邮件投递须分别验收。
