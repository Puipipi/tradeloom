## 对当前设计的约束

统一调度继续使用既有 `WorkflowStep`/attempt；DSH 原生 subagent 负责专家会话，不能再叠一套业务 scheduler。外部源码是静态参考，不是新增功能授权，也不证明生产运行兼容。当前 TradeLoom native bridge 的真实 Host、真实 provider/model 与 GUI 验收状态，以[原生桥检查点](verification/2026-10-24-native-workflow-bridge.md)为准。
