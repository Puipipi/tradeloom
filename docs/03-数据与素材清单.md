## 印刷交付规格（P1 切片的验收线）

画册/单页交给印刷厂，**错了就是重印，重印就是钱**。以下是最低要求，交稿前逐项自检：

| 项目 | 要求 | 常见坑 |
|---|---|---|
| 色彩模式 | CMYK（图片不可留 RGB） | 屏幕鲜亮的橙色印出来发暗 |
| 分辨率 | ≥ 300 ppi（按实际印刷尺寸算） | 微信转发的图通常只有 72 ppi |
| 出血 | 3 mm，四边都有 | 底色铺满页时露白边 |
| 字体 | 全部转曲或嵌入 | 印刷厂没有你的字体，版式全乱 |
| 文件格式 | PDF/X-4（或厂方指定） | 直接给 AI/PSD 源文件，厂方排版会改坏 |
| 总墨量 | ≤ 300%（视纸张） | 深色大面积糊版 |
| 黑字 | 单黑 K100，不用四色黑 | 小字套印不准发虚 |
| 图片版权 | 场景图 / 模特图可商用 | 网图给客户画册用 = 法律风险 |
| 页数 | 4 的倍数（骑马订/胶装） | 排完发现 26 页，要重排 |

> **这一节就是"处理成印刷厂要的格式"的具体含义。** Agent 的输出必须能通过上面这张表，否则不算完成。

## 数据脱敏与合规约定

1. 客户名称、联系方式、精确价格，全部替换后再进仓库；原始件放本地 `data/raw/`，**不进 Git**。
2. 图片如含第三方模特或品牌元素，需确认可商用后才可用于对外物料。
3. 涉及税务、报关、合同原文的材料，只做"结构提取"，不整份入库。
4. 仓库内 `data/` 目录仅保留 `README` 与样例结构，真实数据不入库。
