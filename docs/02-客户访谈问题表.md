# 02 · 客户访谈问题表

> **用途**：下一轮访谈用。目标不是"问出他想要什么功能"，而是**用事实和案例把需求钉死**。
> **优先级**：`P0` = 决定 demo 能不能做（必须有答案）；`P1` = 影响方案选型；`P2` = 加分项。
> **记法**：能录音就录音；答不上来就记「不知道」——**「不知道」本身就是重要数据**（说明这里没有记录）。

**建议节奏**：分两次，每次 60–90 分钟。第一次只谈生意（A–D 模块），第二次谈工厂、财务和工具（E–H 模块）。
开场先说：「我不问你要什么功能，我问你现在怎么做、最近一次怎么做的。」

---

## 只有 15 分钟时问这五句

1. 最近一次**报高了丢单**、一次**报低了后悔**，分别是哪个客户、什么数字？
2. 上个月最大的一笔单，从客户询价到收到定金，一共多少个回合、多少天、你回了多少封邮件？
3. 老客户里，最让你睡不着的是哪一个？他最近一次下单是什么时候？
4. 车间昨天的日报表，现在在哪里？谁写的？写完谁看了？
5. 如果明天你出差一周，公司里哪件事会立刻停摆？

---

## 模块 A · 生意盘子（10 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| A1 | 去年营收、订单数、客户数、平均单值大概是多少？ | 决定"多少单才能撑起统计" | P1 |
| A2 | 老客户和新客户各占多少营收？最大一个客户占多少？ | 集中度决定风险叙事，也决定 Agent 先维护谁 | **P0** |
| A3 | 主要出口哪几个国家？各国客户对同一款产品的偏好差异具体在哪（颜色/规格/包装/认证）？ | 选品与报价的画像维度从这里来 | P1 |
| A4 | 自己生产占多少，外协占多少？分别对应哪些工序？ | 决定"生产链"能不能真做 | **P0** |
| A5 | 全年节奏：哪几个展、旺季几月、什么时候开始备货？提前多久？ | Agent 的日历与提醒必须挂在这条曲线上 | **P0** |
| A6 | 团队几个人，分别管什么？谁会用电脑/手机上的新工具？ | 决定交互形态（老板用 vs 跟单用） | **P0** |

## 模块 B · 选品（10 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| B1 | 最近一次「选对了」的品是什么？当时凭什么判断的？现在卖得怎样？ | 要一条完整的正向归因链 | **P0** |
| B2 | 最近一次「选错了」的品是什么？亏了多少？教训是什么？ | 负样本比正样本更能定义规则 | **P0** |
| B3 | 爆款是客户带来的，还是我们自己推的？大概比例？ | 决定选品是"响应型"还是"预测型" | P1 |
| B4 | 看流行趋势用哪些渠道？（客户寄样 / Pinterest / 亚马逊 / TikTok / 同行展会 / 买手） | 决定外部信号源要不要接 | P1 |
| B5 | 一个新品从想法到能报价，要多久、花多少钱？打样费谁承担？ | 这条决定"设计-报价"能不能打通 | P1 |
| B6 | 设计稿自己做还是外包？一张图多少钱？改几轮？ | 决定内容生产链的 ROI | P1 |

## 模块 C · 客户（15 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| C1 | 新客户来源排序：展会 / 国际站 / 独立站 / 老客介绍 / 海关数据 / 领英？各占多少？ | 决定先接哪个渠道的数据 | **P0** |
| C2 | 海关数据买的哪家？一年多少钱？你实际用它做过哪个决策？ | 验证"不够精准"到底卡在哪一环 | P1 |
| C3 | 从认识客户到第一单，平均跟多久、多少个回合？ | 跟进节奏的基线 | **P0** |
| C4 | 现在怎么记跟进？微信置顶？Excel？脑子里？ | 采集方案必须接住现有习惯 | **P0** |
| C5 | 客户沉默多久你会判断"可能要跑"？有什么信号（回复变慢/砍价变狠/开始问别家）？ | 预警规则的种子 | **P0** |
| C6 | 邮件、WhatsApp、微信，三种渠道各占多少？涉及几种语言？ | 决定多语种与渠道接入的优先级 | P1 |
| C7 | 接到询盘时，你脑子里会先看哪几个字段来判断"这单值不值得跟"？ | **最重要的一问**：直接抽出询盘打分卡的维度 | **P0** |

## 模块 D · 报价（15 分钟，核心）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| D1 | 报价怎么算的？能不能给我看一次完整的成本表（可以抹掉具体数字）？ | 成本模型的地基 | **P0** |
| D2 | 利润比一般取多少？什么情况下敢取高、什么情况下必须取低？ | 那个「度」的可操作表达 | **P0** |
| D3 | 举一个最近**报高了丢单**的例子：报了多少、对方期望多少、后来这单去哪了？ | 丢单是唯一没有日志的失败 | **P0** |
| D4 | 举一个最近**报低了后悔**的例子：事后算下来实际利润多少？ | 隐性成本的证据 | **P0** |
| D5 | 报价里除了材料和工价，还固定要考虑哪些？模具、打样、包装、运费、关税、退税、认证、汇率、账期？ | 逐项确认，别漏 | **P0** |
| D6 | 常见付款方式有哪几种？30/70 还是信用证？对方账期多久？ | 决定资金成本要不要进报价模型 | P1 |
| D7 | 报价单长什么样？有模板吗？中英文都要吗？ | 直接决定输出物形态 | **P0** |
| D8 | 手里的历史报价单和成交单大概有多少份？在 Excel、邮件还是纸面上？ | **数据可得性决定 RAG 可行性** | **P0** |

## 模块 E · 供应商与采购（10 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| E1 | 现在稳定合作的供应商几家？怎么找到的？ | 供应商库规模 | P1 |
| E2 | 同一款货，你会同时问几家？比价时怎么归一（含税？含运费？含模具？）？ | 比价表的字段 | P1 |
| E3 | 有没有供应商档案？记了什么？谁在维护？ | 判断"建档"到底难在哪 | P1 |
| E4 | 最近一次交期延误，原因是什么？你怎么提前发现的（还是没发现）？ | 预警场景的真实素材 | **P0** |
| E5 | 品质出问题时怎么处理？有没有验货报告/返工记录？ | 品质数据的载体 | P2 |

## 模块 F · 生产现场（15 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| F1 | 一道订单要经过哪几道工序？每道工序几个人？ | 工序图是生产链的骨架 | **P0** |
| F2 | 日报表现在怎么填？纸质、微信群还是 Excel？谁能填？ | 采集入口必须贴合现实 | **P0** |
| F3 | 填上来的数据你看吗？看了用来干什么？ | 决定"生成什么"才有用 | **P0** |
| F4 | 工价怎么定？计件还是计时？不同工序的工价差多少？ | 工价表 + 效率口径 | P1 |
| F5 | 交期怎么排？谁排？有排产表还是拍脑袋？ | 交期预警的输入 | P1 |
| F6 | 良品率和损耗率大概是多少？有数据吗？怎么算的？ | 判断能不能做成本看板 | P2 |
| F7 | 旺季缺人吗？怎么补？熟手流失率多少？ | 人事链的真实痛点 | P2 |

## 模块 G · 财务与合规（10 分钟）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| G1 | 从付材料款到收到尾款，一般多少天？最长的一次多少天？ | 现金周期的实测值 | P1 |
| G2 | 现在最担心税务上的哪件事？外包会计替你挡了什么、挡不了什么？ | 合规场景的边界 | P1 |
| G3 | 降资这件事进展到哪一步？最怕哪里出问题？ | 真实合规案例，可做"提醒"场景 | P1 |
| G4 | 有没有被汇率或退税坑过的经历？损失大概多少？ | 量化风险，才好设计提醒 | P2 |

## 模块 H · 工具与数据（10 分钟，收尾）

| # | 问题 | 为什么问 | 级别 |
|---|---|---|---|
| H1 | 现在在用什么软件？国际站后台、企业微信、进销存、财务软件，各自用得多深？ | 别做重复功 | **P0** |
| H2 | 数据都在谁手里？如果这个人离职，会带走什么？ | 数据主权——老板最痛的一击 | P1 |
| H3 | 你每天花时间最多的三件事是什么？（请按真实时间排） | 用来校验我们的优先级对不对 | **P0** |
| H4 | **如果有一个不下班的助理，你最想先让它替你干哪一件？为什么是这件？** | 唯一的开放式问题，放在最后问 | **P0** |
| H5 | 这件事如果做成了，你会怎么判断它"有用"？ | 验收标准由客户给，不由我们给 | **P0** |

## 附录 A · 不要问的问题

| 不要问 | 因为 |
|---|---|
| 「你想要什么功能？」 | 会得到功能清单，得不到问题 |
| 「如果有 AI 帮你写报价，你觉得怎么样？」 | 诱导性提问，答案一定是"好啊" |
| 「你们的痛点是什么？」 | 太抽象，人会答成行业套话 |
| 「这个能省你多少时间？」 | 时间不是他的计价单位，钱和风险才是 |

**要问的永远是**：最近一次是什么时候、具体哪个客户、具体多少数字、你当时怎么处理的。

## 附录 B · 现场记录模板

```
对象 / 角色：            日期：            时长：
【事实】他描述的最近一次具体事件（时间、数字、人）
【原话】值得直接引用的句子
【流程】他实际的操作顺序（不是他以为的顺序）
【数据】他手上真的有的东西：文件、截图、表格（当场要）
【矛盾】他说的和做的不一致的地方
【待补】没答上来的问题编号
```
