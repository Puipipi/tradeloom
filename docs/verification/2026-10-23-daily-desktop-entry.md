# 每日桌面入口（2026-10-23）

本次增加了一个薄的 Windows 桌面启动包装器，交给已有本地控制器执行一次 `start`。包装器等待该控制器结束，不实现 PostgreSQL、服务 readiness、重试或第二套进程管理。控制器退出成功时保持安静；检测到控制器精确报告两种已知重复状态时显示简短提示并返回成功；其他失败显示固定说明与入口日志位置，不把原始 stderr 或异常内容放入对话框。

入口脚本要求调用方提供控制器、Node.js 和日志目录的绝对路径。它为每次调用在指定日志目录写入独立 stdout/stderr 文件。仓库不保存个人路径或本机配置。本机已创建一个“织贸助手（本地开发）”桌面快捷方式，调用该入口并指向已确认的本地控制器与 owned 日志目录。

## 源码验证

`scripts/tests/launch-local-desktop.test.ps1` 使用临时目录和无害 Node 合成控制器，覆盖正常返回、两种精确识别的重复启动状态、其他非零失败、缺失可执行文件、含空格路径、日志捕获及错误提示不泄露原始诊断。测试将通知函数替换为收集器（mock notifier），不显示真实对话框，也不启动 TradeLoom、数据库或桌面窗口。

快捷方式字段已通过文件回读核对。尚未实际点击快捷方式，也未验证实际窗口焦点、真实对话框视觉效果或启动前窗口状态；这些桌面行为仍需单独验收。

已有本地启动守卫及两种应用入口的背景见[本地启动与协作说明](2026-10-23-local-start-entry.md)。
