# 访谈来源与中心只读工具闭环验证

本记录描述 2026-10-23 的本地验证范围，不代表整项产品目标或桌面体验已验收。

## 来源留档

通过现有工作台通道完成一次来源上传（HTTP 201）及一次说明追加（HTTP 201）。说明记录为二次摘要与分析，录音日期为空，核听状态为“未核听”，内容状态保持“待确认”。上传原件在验证前后保持不变；正文仅在进程内比对，没有写入公开报告。原件已按工作台设计保存在本地来源存储中，报告不持久化正文。

数据库只读核对显示：15 项既有计数中，来源版本增加 1、操作回执增加 2，其余 13 项不变；单独的说明修订表增加 1。产品、任务、证据和生产要求等业务记录未发生变化。

## 中心只读工具

通过真实原生 DSH Host 的中心会话发起一次提问，来源列表和有界摘录各完成一次 GET（均 HTTP 200），工具轮次完成。主 provider 请求 3 次，另有 1 次辅助请求；均由本地合成 provider 处理，不涉及付费模型或真实模型效果评估。7 项受保护配置指纹核对通过。来源正文只在进程内与已留档原件比对，native 会话可能在本机保存工具结果；本公开记录不包含正文、文件名、来源标识或摘要值。

受控服务窗口完成后，服务已恢复。独立进程复核确认数据库计数及说明记录未变化，PostgreSQL 仍为同一运行实例，受保护配置指纹核对通过。验证只覆盖服务与数据状态，不代表真实桌面交互。

## 停止握手修复

修复了 launcher 与控制进程之间延迟确认的 named-pipe 停止握手，并增加 UTF-8 分块响应覆盖。针对延迟确认及拒绝响应的行为测试先得到 2 项失败证据；分块 UTF-8 测试先得到 1 项失败证据。最终 `core.test.mjs` 为 22 项通过、0 项跳过。更早一次因导入缺失而失败的测试不属于行为回归证据；各轮原始记录均保留。

先前一次窗口尝试未启动 native probe；另一次 probe 因测试环境未设置来源存储根目录且辅助 provider 请求处理不正确而失败。修正测试环境后，后续独立窗口验证通过。旧报告保持原样，不能将早期失败改写为通过。

## 尚未覆盖

没有完成真实桌面窗口视觉验收，主题、Dockview 拖动与合并、菜单交互及实体手机体验均未验证；用于界面自动化的 app-server 因工具路径不存在而启动失败。HTTP 响应、进程状态和自动化测试不能替代这些验收。

每会话模型选择与 MCP/Skills 能力查看和按角色配置 API/UI 已实现，并通过 Node suite 与隔离官方 runtime 验证；本次中心只读工具窗口没有修改实际用户 profile 配置。生产确认与报工、ERP 正式写入或真实模型调用仍未验证。后续本地激活与其有限服务验收见[工作台本地激活记录](2026-10-23-workbench-local-activation.md)。GitHub 尚未推送，历史隐私审计仍待处理。以上未验证项不应视为已完成。
