## 一、赛题二原文

> **基于华为云 AgentArts 智能体开发平台的 Agent 设计和应用**

**应用领域**：休闲娱乐、办公助手、行业应用、生活服务等场景不限。鼓励发掘真实业务痛点，打造具备落地潜力的智能体解决方案。典型方向包括但不限于：

- **行业赋能型**：针对医疗、教育、金融、制造、农业等行业的智能化解决方案
- **效率提升型**：办公自动化、智能客服、数据分析、文档处理等提效工具
- **创新探索型**：多 Agent 协同、自主决策、MCP 工具调用、持续学习等前沿技术应用
- **生活服务型**：健康管理、出行规划、学习辅助、智能家居等生活场景应用

**任务要求**

- 基于华为云 AgentArts 平台完成智能体的**构建、编排与部署**
- 通过**可视化 Demo 页面**展示核心功能与交互流程
- 应体现 AgentArts 在**智能体设计、工具编排、知识接入、多 Agent 协作、效果评估**等环节的使用价值
- 鼓励形成「**场景识别 → Agent 架构设计 → 技能编排 → 调试优化 → 部署上线**的完整闭环」的高效开发实践

**分享要求**：入围中国总决赛和全球总决赛的作品需在华为云开发者社区或其他社媒平台发布作品分享帖，建议包括：

- Agent 设计方案说明（场景定义、编排思路、工作流架构）
- 知识库 / 语料的构建方法
- 自定义 Skill 或 MCP 服务说明（如有）
- 使用文档与操作指引
- Demo 截图或演示视频链接

**开发工具**：华为云智果（AgentArts）智能体平台

**云服务资源**

- 华为云 MaaS 服务 **Token Plan 套餐代金券**，支持参赛团队调用大模型能力
- 限定云服务的**云资源代金券**，助力作品完成云端部署与在线演示
- 注：预计 **10 月启动代金券申请**，具体资源发放方式、额度、使用范围和有效期以大赛组委会最终通知为准

**学习与部署资源**

- 产品链接：<https://www.huaweicloud.com/product/agentarts.html>
- 用户指南：<https://support.huaweicloud.com/agentarts/index.html>

**注意这句话**：场景「不限」，但**平台是限定的**。这不是一个自由选题，是一道「在 AgentArts 上把一件事真正做成」的题。

**我们在四类方向里的位置**：主 **效率提升型**（展会物料与报价文档处理），副 **行业赋能型**（外贸制造业）；创新探索型的成分（多 Agent 协同、MCP/Skill、效果评估闭环）作为技术叙事，而不是主标签——标签写多了，反而显得没有落点。

## 三、平台事实：AgentArts（智果）

| 能力 | 对我们的意义 |
|---|---|
| 可视化低代码，一站式智能体构建与运营 | 主体必须在平台里搭，不能交一个纯自研后端 |
| 工作流编排画布（大模型 / 提问器 / 意图识别 / 消息 / 结束节点，节点可加注释） | 「编排」是评分可见的东西，画布本身要能讲出故事 |
| 知识库（KooSearch，单智能体最多挂 10 个，支持三方 Embedding） | 历史报价单、工序表、供应商档案走知识库，不自己造 RAG |
| 插件 / Skill 资产广场（预置 50+ 模板与插件） | 能用现成的就别自己写 |
| 代码节点（FunctionGraph）、HTTP 请求节点 | 重计算（排版、PDF 生成）走函数或外部服务 |
| 多智能体协同 | 赛题明确提到平台能力，是加分叙事 |
| 应用观测与效果评估（标准测试集检验） | 可以拿出「回测命中率」这类硬指标 |
| 支持导入 Dify 工作流 DSL | 迁移路径，不是初选路径 |

## 四、这意味着四条硬约束

1. **可运行主体在 AgentArts 里。** 我们的代码仓库定位随之改变：不是"后端服务"，而是**平台侧的节点函数、提示词、知识库语料、测试集与评测脚本**。
2. **必须有可视化 Demo 页面。** 交互流程要能被评委看见：输入什么、Agent 做了什么、产出什么、人在哪一步拍板。
3. **必须"真实业务痛点"。** 赛题原文这句话，正好对上我们手上的真实企业访谈——这是我们相对于"想一个场景"的队伍的差异点。
4. **入围后要发作品分享帖。** 提前想好一篇技术分享怎么写（这也是最好的方案书素材）。

## 六、时间倒排（从今天 2026-10-17 起）

| 时间 | 必须完成 | 说明 |
|---|---|---|
| 10 月下旬 | 组队 + 报名材料就位；拿到赛题二分值细则 | 报名 11-30 截止，但校内流程通常提前 |
