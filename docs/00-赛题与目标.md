# 00 · 赛题与目标

**当前参赛定位：第十一届华为 ICT 大赛（2026–2027）创新赛，赛题1「基于华为云产品打造AI创新应用」。**

织贸助手面向工贸一体制造与外贸团队，整理业务资料、保留来源，并准备供人工审核的草稿与交付物。产品目录与样品清单是应用示例；生产要求、执行计划和 ERP 接入仍属于草稿框架，待进一步验收。当前目标是把已有工作台整理为可验证的华为云应用；现有桌面产品不代表已经满足全部参赛要求。

|---|---|

CodeArts 代码智能体与 AgentArts 智能体开发平台是不同产品：前者属于本赛题明确的开发工具要求，不能用后者的接入记录代替。云代金券和限定资源属于官方资源支持，发放方式、额度、范围和有效期以组委会通知为准，不把领取资源写成已完成事项。

本页不沿用旧赛题二的评分、平台限定或验收结论。提交物、阶段要求、评分与时间安排请直接核对官方最新规则。

## 项目目标

- 围绕产品资料、缺项确认、目录与样品清单建立可复现的业务演示。
- 用明确来源、人工审核与可追溯交付物说明 AI 的实际作用。
- 补齐 CodeArts 使用、华为云服务接入、云端部署及可视化 Demo 的真实证据。
- 区分源码、固定发布包、开发候选和云端部署，逐项记录验收条件与限制。
