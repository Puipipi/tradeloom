## 一、赛题二原文

> **基于华为云 AgentArts 智能体开发平台的 Agent 设计和应用**

**应用领域**：休闲娱乐、办公助手、行业应用、生活服务等场景不限。鼓励发掘真实业务痛点，打造具备落地潜力的智能体解决方案。典型方向包括但不限于：

- **行业赋能型**：针对医疗、教育、金融、制造、农业等行业的智能化解决方案
- **效率提升型**：办公自动化、智能客服、数据分析、文档处理等提效工具
- **创新探索型**：多 Agent 协同、自主决策、MCP 工具调用、持续学习等前沿技术应用
- **生活服务型**：健康管理、出行规划、学习辅助、智能家居等生活场景应用

**任务要求**

- 基于华为云 AgentArts 平台完成智能体的**构建、编排与部署**
- 通过**可视化 Demo 页面**展示核心功能与交互流程
- 应体现 AgentArts 在**智能体设计、工具编排、知识接入、多 Agent 协作、效果评估**等环节的使用价值
- 鼓励形成「**场景识别 → Agent 架构设计 → 技能编排 → 调试优化 → 部署上线**的完整闭环」的高效开发实践

**分享要求**：入围中国总决赛和全球总决赛的作品需在华为云开发者社区或其他社媒平台发布作品分享帖，建议包括：

- Agent 设计方案说明（场景定义、编排思路、工作流架构）
- 知识库 / 语料的构建方法
- 自定义 Skill 或 MCP 服务说明（如有）
- 使用文档与操作指引
- Demo 截图或演示视频链接

**开发工具**：华为云智果（AgentArts）智能体平台

**云服务资源支持**

- 官方页面将华为云 MaaS Token Plan 与限定云资源代金券列为参赛资源支持。
- 具体资源发放方式、额度、使用范围和有效期以大赛组委会通知为准；不能据此把取得代金券写成赛题硬要求或项目硬依赖。

**学习与部署资源**

- 产品链接：<https://www.huaweicloud.com/product/agentarts.html>
- 用户指南：<https://support.huaweicloud.com/agentarts/index.html>

**注意这句话**：场景「不限」，但**平台是限定的**。这不是一个自由选题，是一道「在 AgentArts 上把一件事真正做成」的题。

**我们在四类方向里的位置**：主 **效率提升型**（展会物料与报价文档处理），副 **行业赋能型**（外贸制造业）；创新探索型的成分（多 Agent 协同、MCP/Skill、效果评估闭环）作为技术叙事，而不是主标签——标签写多了，反而显得没有落点。

## 三、平台事实：AgentArts（智果）

| 能力 | 对我们的意义 |
|---|---|
| 可视化低代码，一站式智能体构建与运营 | 主体必须在平台里搭，不能交一个纯自研后端 |
| 工作流编排画布（大模型 / 提问器 / 意图识别 / 消息 / 结束节点，节点可加注释） | 「编排」是评分可见的东西，画布本身要能讲出故事 |
| 知识库（KooSearch，单智能体最多挂 10 个，支持三方 Embedding） | 历史报价单、工序表、供应商档案走知识库，不自己造 RAG |
| 插件 / Skill 资产广场（预置 50+ 模板与插件） | 能用现成的就别自己写 |
| 代码节点（FunctionGraph）、HTTP 请求节点 | 重计算（排版、PDF 生成）走函数或外部服务 |
| 多智能体协同 | 赛题明确提到平台能力，是加分叙事 |
| 应用观测与效果评估（标准测试集检验） | 可以拿出「回测命中率」这类硬指标 |
| 支持导入 Dify 工作流 DSL | 迁移路径，不是初选路径 |

## 四、这意味着四条硬约束

1. **可运行主体在 AgentArts 里。** 我们的代码仓库定位随之改变：不是"后端服务"，而是**平台侧的节点函数、提示词、知识库语料、测试集与评测脚本**。
2. **必须有可视化 Demo 页面。** 交互流程要能被评委看见：输入什么、Agent 做了什么、产出什么、人在哪一步拍板。
3. **优先选择真实业务痛点。** 官方鼓励有真实痛点和落地潜力的场景，但题目领域不限；具体企业问题和规则仍以访谈为准。
4. **入围后要发作品分享帖。** 提前想好一篇技术分享怎么写（这也是最好的方案书素材）。

## 五、评分与材料（官方原文，已补齐）

### 5.1 初赛（材料评审）

| 维度 | 权重 | 官方描述要点 |
|---|---|---|
| **创新性** | **60%** | AI 应用场景的创新（新场景，或传统场景的新突破）；与行业现有方案形成差异化优势；**智能体设计思路或交互方式的创新性** |
| 应用价值 | 40% | 精准定位真实需求并解决对应问题；商用落地潜力、可复制性与规模化前景；Agent 架构设计合理、可行 |

**需提交**：作品信息收集表（Word），以及其他作品介绍 PPT / 设计文件 / 演示视频（如有）。材料中须呈现：

- 作品简介与创意点
- 团队介绍
- **Agent 设计方案（场景定义、编排思路、工作流架构、模型与资产选择）**
- 面向的行业问题 / 落地场景
- **作品 Demo 视频展示（基于 AgentArts 构建与运行的完整流程）**

### 5.2 中国总决赛（100% 由答辩当天评委评议）

| 维度 | 权重 | 说明 |
|---|---|---|
| 创新性 | 40% | 智能体编排设计、**多 Agent 协作**、**MCP 工具调用**或**知识库构建**等方面的创新 |
| 应用价值 | 35% | 同上，另需**能证明呈现结果的有效性和严谨性** |
| 完整性与可展示性 | 15% | 材料完整（背景、Agent 设计方案、工作流架构、知识库构建方法、效果验证）；有可交互演示；**基于 AgentArts 的开发流程展示完整** |
| 答辩表现 | 10% | 演讲流利、观点清晰 |

**需提交**：答辩 PPT；**可在线访问和交互的 Demo 页面地址**；Agent 设计方案文档；自定义 Skill 或 MCP 服务说明（如有）；**社区分享帖截图**。

| 维度 | 权重 |
|---|---|
| 创新性 | 40% |
| 应用价值 | 30% |
| 完整性与可展示性 | 15% |

**需提交**：在总决赛材料基础上，增加**应用与落地进展说明**、**社区反馈数据（阅读量、互动量等）**。

**边界说明**：官方原始响应中的“英文答辩总分加 2 分”位于赛题二内容之前、上一赛题评分表末尾；赛题二评分块没有这项文字。赛题二是否适用需向组委会确认，不把它作为赛题二加分承诺。

### 5.4 项目策略建议（不等同于赛题硬要求）

1. **初赛创新性占 60%。** 官方评价设计思路或交互方式创新；“人工确认 + 来源可追溯”可作为项目方案选择，不是官方指定业务，也不能由此推出要开发报价 Agent。
2. **初赛材料包含基于 AgentArts 构建与运行的 Demo 视频。** 可视化展示编排和交互有助于评审理解；画布、节点或知识检索的具体镜头属于制作建议。
3. **中国总决赛要求可在线访问和交互的 Demo。** AgentArts 平台构建、编排和部署是赛题要求；代金券是资源支持，实际额度和使用条件以通知为准。
4. **入围后需发布作品分享帖。** 官方建议介绍方案、知识库/语料、Skill/MCP（如有）、使用说明和 Demo；全球赛材料还包括应用进展及社区反馈数据。
5. **英文答辩是否加分待确认。** 该文字出现在赛题二之前的上一赛题评分表尾，不作为赛题二已确认的加分项。
