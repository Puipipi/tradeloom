## 剩余验收前置

- **现有隔离环境可继续。** 对照功能矩阵抽取代表性现有角色：商品场景商品助手和交付物场景交付助手分别切出并返回，有已绑定测试会话时核同一身份、历史与未发草稿。总览与工作流中心助手往返已有实测。正式版已实见商品和交付物场景往返，两个角色的未发草稿已实测各自保留，现有夹具仍缺可核的已绑定历史；运行记录空列表和带本地状态事件的列表均实测内部位移，Agent 运行列表与其他窄宽组合仍待相应隔离数据。原生执行详情和业务计划的内部滚动已有实测。R3 历史实测打开两类独立窗。正式候选已实测运行记录独立场景窗四面板及实际关闭，助手面板应用内返坞也已实测。助手角色窗系统 X 后经官方 Computer Use 一次点击实际关闭，同主窗恢复原会话。历史代表操作用于抽样，未要求所有角色与所有场景的全排列。
- **当前仍缺前置。** 推荐布局重置需要已获准的一次性隔离 Web 配对，并由有权持有人通过扫码或剪贴板在宽屏浏览器完成。隔离 Host 曾在私有 IPv4 监听，用户协助后已在隔离宽屏 Chrome 实际进入工作台 Web；正式 rc.3 布局壳未消费场景导航插槽，推荐布局入口未出现，恢复与刷新验证待修复后执行；证据无需保留配对码或个人数据。现行回复朗读须在获准隔离会话中启用，使用当前角色实际完成的回复，现场听到设备播放并验证停止。S5-10 现有原生语音输入入口归入口回归；S5-12、S5-13 已取消，录音与安装依赖未列为本轮入口回归操作，不进行新增语音功能试验。外部网页版 AI 已按用户指示退出本轮回归。 [配对及实测限制](S7-closeout-20261119.md)
- **产品与角色权限待用户决定。** 实际 Canvas 的中心只允许五个非中心 preset，目前均未挂 SDK 文件生产与 `present`；另一条原生任务分派链的 `product/delivery` 限制只适用于该入口。标准 preset 虽有文件与呈递能力，但不在 Canvas 允许列表。若需实证子会话的原生产物，前置是已获授权的允许角色具备工作区文件生产和原生呈递，并产生绑定 child/run 的声明，之后再走目录授权继承、登记和下载。手工文件及既有 HTTP 验证各自保留原范围。 退役或已取消能力继续排除，正式部署未在本次范围内。 [正式 preset 接线]([local-path-redacted]

本索引保留历史波次的时间和验证范围，当前正式构建与原生观察见各自回执。阶段要求以已交接的维护与原功能验证为界，新增功能试验不在本阶段要求内。
