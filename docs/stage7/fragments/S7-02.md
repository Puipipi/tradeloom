## 冻结基线推荐布局问题

冻结源码的 `agent-center` 使用 `collaboration_grid` 且定义了必选 `business-plan`。旧推荐网格只有四个固定 panel ID，但五个必选面板都进入了 `panels`，导致 Host 以 `open views and panel records do not match` 拒绝推荐记录。即使活动场景是 `products`，全场景保存请求里携带的无效 `agent-center` 记录也会导致写校验失败。

作者试验曾让 Host 推荐和客户端本地重置把额外业务面板作为业务主组的非活动标签。R3 实机工作流截图 `[local-path-redacted]` 显示业务计划和工作流画布各自独立可见。集成保留两个默认生成器的冻结实现，排除了试验及新增标签断言。原布局验证和场景配置继续生效。

私有整理保持 DOM/CSS、工具栏顺序、拖放、尺寸、放缩及状态键。布局查找应用于序列化 Dockview 网格，悬浮组投影和独立面板窗口返回仍按各自语义处理；独立场景窗、panel popout 的身份、关闭与授权链沿原生产入口执行。草稿生命周期、场景轮换和共享公共入口未涉及改动。公共改动请求无。

### 同依赖复跑命令

在要验证的工作树根运行。基线命令从给定 Git 对象读取这次变更的三个产品源码和两个测试文件，其余相关文件由当前工作树提供。集成版本使用同一段命令第二步。将基线映射中的两个测试文件移除可比较同测试夹具下的冻结源码和集成源码。

```powershell
$scratch='[local-path-redacted]
$env:TRADELOOM_REACT_LIBRARY="$scratch/node_modules/react/index.js"
$env:TRADELOOM_REACT_SERVER_LIBRARY="$scratch/node_modules/react-dom/server.node.js"

$env:TRADELOOM_DOM_TEST_ROOT=$scratch
$env:TRADELOOM_CORDIS_LIBRARY='[local-path-redacted]
$env:S702_RESOLVE_FROM='[local-path-redacted]

$runner = @'
import fsPromises from 'node:fs/promises'
import { registerHooks, syncBuiltinESMExports } from 'node:module'
import { pathToFileURL } from 'node:url'
import { resolve as abs } from 'node:path'
import { spawnSync } from 'node:child_process'
import { run } from 'node:test'
import { spec } from 'node:test/reporters'
const root = 'packages/tradeloom-shell/'
const baselineCommit = process.env.S702_COMPARE_BASE
const baseline = baselineCommit ? new Map(['dock-layout.js', 'scene-layout.js', 'client.scenes.js', 'tests/dock-layout.test.js', 'tests/scenes.test.js'].map(name => {
  const result = spawnSync('git', ['show', baselineCommit + ':' + root + name], { encoding: 'utf8' })
  if (result.status !== 0) throw new Error(result.stderr)
  return [pathToFileURL(abs(root, name)).href, result.stdout]
})) : new Map()
if (baseline.size) {
  const originalReadFile = fsPromises.readFile
  fsPromises.readFile = function (file, ...options) {
    const url = file instanceof URL ? file.href : typeof file === 'string' ? pathToFileURL(abs(file)).href : null
    if (url?.endsWith('/client.scenes.js') && baseline.has(url)) {
      return Promise.resolve(baseline.get(url))
    }
    return originalReadFile(file, ...options)
  }
  syncBuiltinESMExports()
}
const shellUrl = pathToFileURL(abs(root) + '/').href
const sdkUrl = pathToFileURL(process.env.S702_RESOLVE_FROM).href
registerHooks({
  resolve(specifier, context, nextResolve) {
    if (specifier.startsWith('@deepseek-ai/') && context.parentURL?.startsWith(shellUrl)) {
      return nextResolve(specifier, { ...context, parentURL: sdkUrl })
    }
    return nextResolve(specifier, context)
  },
  load(url, context, nextLoad) {
    if (baseline.has(url)) return { format: 'module', shortCircuit: true, source: baseline.get(url) }
    return nextLoad(url, context)
  }
})
const stream = run({ files: process.env.S702_TESTS.split(',').map(name => root + 'tests/' + name), isolation: 'none' })
stream.on('test:fail', () => { process.exitCode = 1 })
stream.compose(spec).pipe(process.stdout)
'@

$env:S702_COMPARE_BASE='761af0a601052a0337ac795c36e301a9c0162677'
$runner | node | Out-File -LiteralPath "$scratch/repro-baseline.log" -Encoding utf8
$LASTEXITCODE | Out-File -LiteralPath "$scratch/repro-baseline.exit" -Encoding ascii

Remove-Item Env:S702_COMPARE_BASE -ErrorAction SilentlyContinue
```
