Admission uses the existing `ctx.connection.requestRejection` before request handling. The endpoint accepts no query and calls `ctx.tools.schemas()` once without a scope. Global means the registry's global view, not the union of role-specific tools or installed tools. Success returns `{scope: "global", tools: [...]}` with only `name`, `description`, `parameters`, and optional `deferLoading`. Empty is valid. The SDK supplies lossless JSON parameters; failures or JSON serialization errors return 503 `tool-schemas-unavailable`; no catalog is silently truncated. Responses are no-store; no new CORS or tool execution is provided.
