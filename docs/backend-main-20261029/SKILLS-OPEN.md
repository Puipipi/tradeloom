# Skill open contract

`registerSkillsOpen(ctx)` supplies an exact POST `/tradeloom/skills/open` handler for explicit Host assembly. It requires authenticated Host admission, strict same-origin, JSON `{role,expectedSessionId,name,target}`, a live role binding and a complete user-invocable catalog. It depends on `skills.resolveOpenTarget(name, target, {cwd, scope, signal}): Promise<string | undefined>`, delivered separately with the SDK patch. Only the SDK result is used as a path; Host filesystem mapping and desktop availability are checked before handing it to the existing session controller. Success includes `desktop: {name}` and means handed off, not visibly opened. Missing SDK returns 503; unavailable target or mapping returns 422.
