## 总体约束

1. 用户认可粗版并要求按织贸业务逻辑实现：原生 DSH 顶层“应用/编辑”保持紧凑，左侧原生功能侧栏完整保留；chat 是右下独立组件；目标为全窗口工作台。
2. 正文约 16px、主要控件/关键状态约 14px；时间、次要说明和装饰 eyebrow 可用更小层级，整体比原界面易读；避免整行独占的导航按钮。
3. 光晕不能一律当装饰：当前选项/卡片可能表示选中；部分组件光晕表示页面内悬浮打开。只按观察明确语义应用，未知状态标注未知。
4. 织贸已有后端与业务数据优先。排产、报工、ERP/进度、Agent执行等未接通时不得造状态或伪数据；缺报工记录不等于零产出，不混算不同工序/单位，助手自述不算业务完成。
5. 参考仅证明可见画面，不证明其背后交互、权限或运行机制。保留当前功能，不从视觉图推导新的业务能力。

## 分阶段实施映射
### V01 — 工作台顶栏、多面板、文件与会话
- **对应模块：** 全局工作台壳层；产品资料；任务与 Agent 中心；交付物预览。
- **采用：** 横向场景页签与清楚的当前选中态；多面板分区；文件列表/缩略图；会话附件、固定输入区；浮动会话覆盖主区时保留青色描边/层级提示。正文约16px、主要控件/关键状态约14px，次要元信息采用更小层级。
- **状态语义：** S001 高亮当前页签=选中；S025 青色描边会话窗=页面内悬浮/覆盖态；S011 半透明缩略图浮层含义在文字观察中未知，不推断为拖拽/预览动画。
- **不照搬：** SSH、服务器/磁盘指标、运维日志与探活、Blender、ComfyUI 及其硬件/队列指标、Token 用量作为业务指标。技能/插件页只复用真实存在能力的呈现样式。
- **验证待办：** 紧凑顶栏不挤压页面；原 DSH 侧栏/功能仍可达；选中与浮层语义清楚；附件和真实交付文件可区分。

### V02 — 可调窗格、双区/四区与文件预览联动
- **对应模块：** 任务与 Agent 中心；产品资料/交付物预览。
- **采用：** 文档、文件树、助手等可分区组合；改变窗格比例；聊天扩大时其他区仍可辨认；文件/结果卡片对应预览；明确空态。
- **状态语义：** S035 两列比例变化；S036 右侧会话悬浮展开；S029 四区布局作基准。S037 文件名称“外拖中间态”，既有观察未确认拖拽手势，不据此承诺拖出窗口能力。
- **不照搬：** DeepSeek 网页/第三方网站、ComfyUI 控制台、图像测量/框选分析、生成视频；双助手只在真实对照/调试需求存在时显示。
- **验证待办：** 面板调整/扩大还原在桌面可用；任务、来源资料、交付预览和助手各有真实内容/状态。

### V03 — 会话历史、归档、失败/空态和工具设置
- **对应模块：** 任务与 Agent 中心；运行记录与设置。
- **采用：** 历史/归档/续接层级；会话空态；错误信息与继续入口；工具/技能列表按真实功能分组；若存在业务图，只作为可选视图。
- **状态语义：** S047 会话失败状态并有“继续”；S048 红色错误文字（窄裁切，操作未知）；S049 换会话后的空态；S045 标题虽称错误提示，但观察未见可单独确认的错误弹条；节点金色边框 S058 可见但选中语义不确定，不据颜色推断。
- **不照搬：** MCP/插件启停即等同业务权限；Token 数或工具开关推导成本/效率；节点执行/编辑能力；不把颜色当唯一状态信号。
- **验证待办：** 错误、空、运行、完成语义有文字/图标辅助；归档可找回；设置只呈现当前真实能力。

### V04 — 主工作区与结果选择/预览
- **对应模块：** 任务与 Agent 中心；交付物。
- **采用：** 主任务区 + 文件栏 + 可选底部预览 + 助手的可组合布局；选中结果与预览联动；运行/完成状态可读；浮窗扩大时可恢复布局。
- **状态语义：** S063/S084/S086 结果缩略图和预览面板；S082/S083 展示开始/运行状态，但不能仅凭相邻帧推出点击因果；节点青色高亮语义按具体视图验证。
- **不照搬：** SSH/网站运维、Blender 启停、视频/ComfyUI 节点工作流菜单与表单、剪映/OBS 等工具能力。普通用户默认任务列表/待办；图结构仅当真实持久业务流程支持时作为可选视图。
- **验证待办：** 选中业务交付物后预览同一对象；运行状态来自后端；面板可缩放/复原而不丢当前工作。

### V05 — 顶层场景导航、侧栏与消息队列
- **对应模块：** 全局工作台壳层；任务与 Agent 中心。
- **采用：** 顶部场景选择器选中态；完整工作区/会话导航侧栏；消息排队、运行摘要、风险提示的层级；双助手仅用于真实对照。
- **状态语义：** S090 当前场景页签有亮蓝边/光效=当前选中；其他光效如果用于浮起面板，需按对应页面/图确认，不能一律删除或装饰化。
- **不照搬：** 行情/股票、服务器资源/磁盘仪表作为织贸业务；用量或摘要数字冒充生产/报工完成度；不可压缩原侧栏成单条窄历史带。
- **验证待办：** 原侧栏入口和列表层级完整；队列/完成/风险状态用真实会话事件呈现。

### V06 — 文件知识库、健康分类与设置面板
- **对应模块：** 产品资料；交付物；运行记录与设置。
- **采用：** 文件夹/文件列表、路径栏、大小/日期、选中行；文档预览；真实健康检查树；真实技能/插件卡片分组；会话/助手导航。
- **状态语义：** S117 行悬停/选中；S118 选中文件行；S119 以图标/计数呈状态分类；S120 用量弹层仅作会话资源信息参考，不是业务进度。状态须同时可读，不能只靠颜色。
- **不照搬：** 系统磁盘资源仪表、SSH 终端与运维日志、MCP 开关状态作为织贸连接状态、虚构上下文/资源百分比。
- **验证待办：** 路径和文件元数据来自真实文件；健康项来自真实检查；技能/插件页可执行项与已接后端一致。

### V07 — 大文档预览、文件列表与停靠/扩大
- **对应模块：** 产品资料；交付物；任务助手上下文。
- **采用：** 文档预览停靠与扩大；文件列表/路径栏；预览工具栏（刷新、系统打开、定位/复制路径、关闭）仅在当前已有 API 支持时展示；右侧助手保持可见。
- **状态语义：** S131 停靠预览；S132 扩大预览；S133 页面加载空态。S126–S128 是图像抠图工具状态，工具样式不能推导为织贸已有功能。
- **不照搬：** 本地抠图/透明底处理、任意内嵌网页/第三方 HARNESS 页面，不复述截图中的私人正文。
- **验证待办：** 预览引用同一份真实文件；扩大后仍可恢复原布局；加载中/失败/空态明确；未支持的工具按钮不出现。
